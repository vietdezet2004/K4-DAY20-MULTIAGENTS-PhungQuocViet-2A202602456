---
name: organizational-conventions-check
description: Use when ensuring compliance with organizational coding and documentation standards.
---
- Ensure all public functions have type annotations for parameters and return values.
- Maintain a changelog in CHANGELOG.md, documenting each fix under '## Unreleased' with bullet points for each change.
- Do not modify existing test files; create new test files as needed.
- Follow the meta block structure in output files, including necessary metadata such as source and row counts.
- Use lowercase service names with hyphens replaced by underscores in all outputs.
- Ensure all monetary values are represented in integer cents format.
- Document all changes in a clear and concise manner, adhering to the established format.
